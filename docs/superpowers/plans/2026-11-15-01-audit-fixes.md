**Goal:** Fix every data-correctness (D1–D10), security (S1–S3, S5–S7) and quality (Q3–Q6, part of Q1) finding of the 15 Nov audit, each proven by a failing test first.

**Architecture:** Collectors (`lib/services/collectors/`) gather, pure functions in `lib/services/derive/` judge, widgets only show. Every fix lands in the collector or derive layer with an offline test; `HtmlService` only loses code. No new package dependencies.

**Spec:** `docs/audits/2026-11-15-explorer-audit.md`

## Global Constraints

- `flutter analyze --no-pub` and `flutter test` pass after every task. CI uses Flutter 3.47.6.
- A value that is unknown is an `Observed` state (`Unavailable`, `Pending`, `Failed`), never `0`, `''` or `'N/A'`.
- Browser-side JavaScript stays ES5-ish: no arrow functions, no optional chaining, no `let`/`const`.
- Widgets and screens do no fetching, parsing or regex (`test/architecture/no_data_logic_in_ui_test.dart` enforces it).
- No raw `print()` in `lib/`. Mutations only in `ChangeNotifier`s in `services/` or `models/`.
- Cookie and storage values never leave the app (export, logs).
- Small, focused edits; do not reformat or rewrite files beyond the task.
- One commit per task. Message style as in `git log` (`Fix: …`, `Security: …`, `Chore: …`), ending with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`.
- Do not push, tag or open a PR; the owner does that.

## Review Focus

1. Android WebView has no isolated JavaScript world: the collector there must behave exactly as today (Task 4 test `android keeps the page world and the patch`).
2. Recorded fixtures in `test/fixtures/browser/*.json` (storage items with `v`, no navigation sizes) must still parse (Tasks 2 and 3 run against `macos_basic.json`).
3. A hostile frame sends an oversized or malformed `vsvFrame` message: it is dropped, nothing throws (Task 5 test `oversized frame report is dropped`).
4. Hosts that are not ordinary domains (`localhost`, `192.168.1.1`, `[::1]`, empty): `registrableDomain` returns the host itself (Task 6).
5. A browser that reports no navigation sizes (older WebKit): the document falls back to the server body and the total is marked estimated (Task 2).
